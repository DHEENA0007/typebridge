# Security Policy

The TypeBridge project is committed to ensuring the security of its users and the integrity of the ecosystem.

## Supported Versions

We release patches and security fixes for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

## Reporting a Vulnerability

If you discover a potential security vulnerability in TypeBridge, **please do not open a public GitHub issue.**

Instead, report it responsibly via one of the following channels:

1. **GitHub Private Security Advisory**: Submit an advisory via the [Security Advisory tab](https://github.com/typebridge/typebridge/security/advisories/new).
2. **Security Email**: Send an encrypted or plain report to `security@typebridge.dev`.

### What to Include in Your Report

To help us triage and resolve the issue quickly, please include:
- A description of the vulnerability and its potential impact.
- Step-by-step reproduction instructions or a minimal proof-of-concept (PoC).
- Affected version(s) and environment details.
- Any suggested mitigations or patches.

## Response SLA

- **Acknowledgment**: Within 48 hours of receipt.
- **Triage & Severity Assessment**: Within 5 business days.
- **Remediation & CVE Assignment**: Coordinated release with a standard 90-day responsible disclosure window.

Thank you for helping keep TypeBridge safe for everyone!
